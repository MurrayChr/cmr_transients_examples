**Stan model code**

**"01_cjs_transients_epm.stan"** fits the CJS-with-transients model using the 
extended product-multinomial likelihood.

**"02_cjs_transients_hhmm.stan"** fits the CJS-with-transients model using the 
'multievent' or hierarchical hidden Markov model likelihood.

**"03_ms_pm.stan"** fits a multi-state model (with two states, without transients) using the 
product-multinomial likelihood.
